# Selección de modelos de desarrollo

| Escenario | Modelo seleccionado | Justificación                                                                                |
|---        |---                  |---                                                                                           |
| A         | Cascada             | Los requisitos son claros, no necesita cambios, por lo que el riesgo que se corre es menor.  |
| B         | Espiral             | No se sabe el objetivo ni que funcionalidades necesita; esta abierto a cambios constantes.   |
| C         | Incremental         | Requisitos claros pero necesita ser revisado constantemente ya que un riesgo menor puede ser crítico.|
| D         | Evolutivo           | Se busca que los usuarios den retroalimentación del producto con cada iteración.|

## Conclusión
Nosotros seleccionamos el módelo rápido por que estamos más familiarizados con la metodología en cascada y sus requisitos.
